# GSU Study Spaces

A single-page site for finding study spots around Georgia State University's Atlanta campus, including places not owned by GSU.

## Features
- Search, sort, and filter by Wi-Fi, outlets, quiet, group-friendly, food, reservable rooms, and not owned by GSU
- Detail panel with noise, seating, food and drinks, and a link to check current hours
- Star ratings, written reviews, report review button, and admin mode to remove reviews
- Table of every place with food, drinks, and where to check closing times

## Run it
Open `index.html` in any browser. No install needed.

## Notes
- Reviews are sample data and reset on refresh.
- Closing times are not verified. Each place links to its current hours.
- The GSU logo is a trademark of Georgia State University. Get permission before making the site public.
